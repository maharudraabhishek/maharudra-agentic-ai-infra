## Notes

- `approval-required` and `agent-allowlist` are declared in `RefusalReason` but not yet wired — those branches live outside `DefaultPermissionGate` and are plumbed in Stage 26.
- `satisfies RefusalReason` type assertion used at each deny branch to catch taxonomy drift at compile time without a runtime cast.
- `runWithRetry` is a pure async function — no harness state mutation (D37). Executors compose it; the harness executes individual attempts.
- Backoff test uses 30ms with 25ms lower bound to tolerate ~5ms timer slack on Windows CI.
