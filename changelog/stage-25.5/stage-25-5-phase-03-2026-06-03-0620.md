## Notes

- `per-tool` guard timing is intentionally absent from `AgentGuardTiming`. Stage 21 D1 forbids Layer 9 from calling Layer 11 for LLM-judge guards. Heuristic-only per-tool checks belong in the Input Guard (Phase 01).
- `mode: "json-schema"` is in the taxonomy but enforcement is deferred to Stage 26 (depends on `outputSchema`).
- The AbortController signal is wired but NOT threaded into tool handlers — that's Stage 26/27. The `agent.timeout` code path is exercisable via `maxRuntimeMs: 1` once an awaiting handler exists.
- Multi-agent `maxToolCalls` violations are soft (warnings). Single-agent violations are hard (fail). This asymmetry is intentional: Stage 26's orchestrator adds per-role isolation for the multi-agent path.
- `maxIterations` has no default and no enforcement today — Stage 48 SelfCritiqueLoop consumes it.
