## Changed

- `PermissionGateInput` — added optional `agentId?: string` so callers can identify the agent requesting a tool without changing legacy callers.
- `AgentHarnessToolInput` — added optional `agentId?: string` and threads it into `PermissionGateInput`.
- `DefaultPermissionGate` — constructor now accepts optional `AgentDefinitionRegistry`; the new argument is optional and direct `new DefaultPermissionGate()` call sites remain valid.
- `DefaultPermissionGate.decide()` — added early `approval-required` refusal when the resolved agent requires approval and `DefaultApprovalPolicy.requiresApproval(tool)` returns true.
- `DefaultPermissionGate.decide()` — added late `agent-allowlist` refusal when the resolved agent has `allowedTools` and the requested tool id is absent.
- `AgentHarness` — constructor accepts optional `agentRegistry?: AgentDefinitionRegistry` for the default gate; custom `permissionGate` callers keep ownership of their own lookup behavior.
- `LocalStdioMcpRuntimeAdapter` — passes `container.agentRegistry` into the default `AgentHarness` call site.
- `RemoteRuntimeAdapterBase` — passes `container.agentRegistry` into the default `AgentHarness` call site used by remote-safe surfaces.
- `packages/agentic-ai-infra-runtime/src/harness/README.md` — documents agent identity policy and gate order.
- `docs/04-core-framework/agent-definition-and-registry.md` — updates execution-time `allowedTools` and `approvalPolicy.requiresApproval` semantics.
- `prompts/stage-26/verification-summary.md` — records Phase 04 as the newest completed phase with actual CI evidence.
- `STATUS.md` — records the current Stage 26 Phase 04 frontier and green CI state.
- `kb.md` — records the durable D-F1/refusal-taxonomy decision notes.
- `STRUCTURE.md` — indexes the new runtime harness test file and this changelog entry.
