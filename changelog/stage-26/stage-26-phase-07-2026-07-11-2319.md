## Added

- `SingleAgentExecutorInput.agentId?` — selects the canonical registered
  definition used for execution policy and attribution.
- `SingleAgentExecutorInput.traceId?` — correlates a single-agent executor
  report with its owning orchestration trace.
- `SingleAgentRunReport.agentId` — records the canonical executed agent id.
- `FrameworkError.refusalReason?` — preserves a closed policy-denial reason
  across framework and retry boundaries.

## Changed

- `SingleAgentExecutor.execute()` now resolves one canonical definition and
  applies its role, allowlist, token budget, response policy, eval rules, and
  report attribution; an explicitly unknown id fails closed.
- `AgentOrchestrator.run()` now canonicalizes route entries, propagates and
  verifies agent/trace identity, contains injected seam throws, enforces
  content and response actions, and records typed parallel refusals.
- `DefaultPermissionGate` and `AgentHarness.executeTool()` now order baseline
  permission checks before exact approval so valid approval can reach a handler
  without bypassing runtime-mode, capability, role, remote-safe, or allowlist
  policy.
- `runWithRetry()` now preserves an input `refusalReason` when returning
  `agent.retry-blocked` or `agent.retry-exhausted`.
- Deterministic single-agent outputs no longer treat every available context
  source as cited evidence.
