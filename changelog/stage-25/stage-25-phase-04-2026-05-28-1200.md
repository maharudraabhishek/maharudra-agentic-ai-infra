## Added

- `packages/agentic-ai-infra-runtime/src/agents/index.ts` — `enforceAllowedTools()` (function): pure helper; intersects an executor's tool list against a definition's `allowedTools` set; returns filtered list; no-op when `allowedTools` undefined
- `packages/agentic-ai-infra-runtime/src/agents/index.ts` — `effectiveBudgetCeiling()` (function): pure helper; returns `Math.min(executorBudget, definition.budgetPolicy.maxTotalTokens)` when policy is set; returns executor budget unchanged when no policy
- `packages/agentic-ai-infra-runtime/src/agents/index.ts` — `RuntimeRoleOutput` (type): `DeterministicAgentOutput & { selectedToolIds: readonly string[] }` intersection; carries post-enforcement tool list with each role output

## Changed

- `packages/agentic-ai-infra-runtime/src/agents/index.ts` — `RuntimeMultiAgentRunReport`: `roleOutputs: readonly RuntimeRoleOutput[]` field added
- `packages/agentic-ai-infra-runtime/src/agents/index.ts` — `SingleAgentExecutor.execute()`: looks up `"manager"` definition via `agentRegistry?.findById("manager")`; applies `effectiveBudgetCeiling` to cap `budget.maxTotalTokens`; applies `enforceAllowedTools` to intersect tool list; report's `selectedToolIds` reflects post-enforcement list. When `agentRegistry` absent, behaviour is byte-for-byte identical to Stage 24 (D23).
- `packages/agentic-ai-infra-runtime/src/agents/index.ts` — `TokenEfficientMultiAgentExecutor.execute()`: computes `executorAllowedTools` once; per routed role calls `findByRole(role)[0]`, applies `enforceAllowedTools` + `effectiveBudgetCeiling`, caps `tokenUsage` via `Math.min`; collects into `roleOutputs[]`. When `agentRegistry` absent, behaviour is byte-for-byte identical to Stage 24 (D23).
